# Staff Schedule & Timesheet Application

Объединённое приложение для управления штатным расписанием, графиками сотрудников и табелированием.

## Функциональность

### Администратор
- Управление объектами (филиалы, площадки)
- Управление должностями
- Управление сотрудниками
- Управление шаблонами смен
- Создание и управление расписаниями

### Менеджер объекта
- Просмотр графиков своих сотрудников
- Табелирование (отметка прихода/ухода)
- Управление командой
- Просмотр статистики

## Технологический стек

- **Frontend**: Next.js 16, React 19, TypeScript
- **Стили**: Tailwind CSS
- **База данных**: Supabase (PostgreSQL)
- **Аутентификация**: Supabase Auth

## Установка

1. Клонируйте репозиторий
```bash
git clone <repository-url>
cd webURVS
```

2. Установите зависимости
```bash
npm install
# или
yarn install
# или
pnpm install
```

3. Создайте файл `.env.local` на основе `.env.example`
```bash
cp .env.example .env.local
```

4. Добавьте ваши Supabase учётные данные в `.env.local`

5. Запустите приложение
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## База данных

Таблицы:
- `profiles` - Профили пользователей
- `facilities` - Объекты (филиалы)
- `positions` - Должности
- `employees` - Сотрудники
- `shift_templates` - Шаблоны смен
- `schedules` - Расписания
- `timesheets` - Табелирование

Все таблицы защищены Row Level Security (RLS) политиками.

## Развертывание

Приложение готово к развёртыванию на Vercel или других платформах, поддерживающих Next.js.
