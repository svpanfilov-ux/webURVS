# Функции приложения Staff Schedule & Timesheet

## 1. Администратор - Управление системой

### 1.1 Управление объектами (Facilities)

**Возможности:**
- ✅ Создание новых объектов (филиалы, площадки)
- ✅ Редактирование информации об объекте
- ✅ Удаление объектов
- ✅ Просмотр всех объектов
- ✅ Привязка сотрудников к объектам

**Информация объекта:**
- Название
- Адрес
- Описание
- Дата создания

### 1.2 Управление должностями (Positions)

**Возможности:**
- ✅ Создание должностей для каждого объекта
- ✅ Установка оклада/часовой ставки
- ✅ Установка требуемого количества сотрудников
- ✅ Редактирование и удаление должностей

**Информация должности:**
- Название
- Описание
- Часовая ставка
- Требуемое количество человек

### 1.3 Управление сотрудниками (Employees)

**Возможности:**
- ✅ Добавление новых сотрудников
- ✅ Привязка к должности
- ✅ Привязка к объекту
- ✅ Отслеживание даты найма
- ✅ Изменение статуса (активный/неактивный)

**Информация сотрудника:**
- Имя и фамилия
- Должность
- Объект работы
- Контактные данные (телефон, email)
- Дата найма
- Статус

### 1.4 Управление шаблонами смен (Shift Templates)

**Возможности:**
- ✅ Создание стандартных смен
- ✅ Установка времени начала и окончания
- ✅ Автоматический расчет продолжительности
- ✅ Переиспользование шаблонов

**Шаблон смены включает:**
- Название (например "Смена утренняя 8-16")
- Время начала (08:00)
- Время окончания (16:00)
- Продолжительность в часах
- Описание

### 1.5 Создание расписаний (Schedules)

**Возможности:**
- ✅ Создание расписания для сотрудников
- ✅ Выбор шаблона смены или указание времени вручную
- ✅ Назначение на конкретную дату
- ✅ Добавление заметок (особые указания)
- ✅ Сброс графиков
- ✅ Копирование расписания на несколько дней

**Распределение смен:**
- По объектам
- По сотрудникам
- По датам
- Проверка: не может быть 2 смены в один день

## 2. Менеджер объекта - Управление командой

### 2.1 Просмотр расписания (Schedule View)

**Возможности:**
- ✅ Просмотр расписания своей команды
- ✅ Календарный вид графика
- ✅ Фильтрация по дате
- ✅ Просмотр информации о сотруднике
- ✅ Просмотр смен на день

**Информация на день:**
- Список сотрудников на смену
- Время начала/окончания смены
- Статус присутствия

### 2.2 Табелирование (Timesheet)

**Возможности:**
- ✅ Отметка прихода (Check-In)
- ✅ Отметка ухода (Check-Out)
- ✅ Указание времени начала смены
- ✅ Указание времени окончания смены
- ✅ Добавление заметок (опоздание, ранний уход и т.д.)
- ✅ Просмотр истории табелей

**Табель включает:**
- Дата
- Время прихода
- Время ухода
- Общее время работы (рассчитывается автоматически)
- Статус (ожидает подтверждения, одобрено, отклонено)
- Заметки

### 2.3 Управление командой (Team)

**Возможности:**
- ✅ Просмотр всех сотрудников объекта
- ✅ Просмотр информации о сотруднике
- ✅ Фильтрация по статусу
- ✅ Поиск сотрудника

**Информация о команде:**
- ФИО сотрудника
- Должность
- Статус (активный/неактивный)
- Последний табель

### 2.4 Статистика

**Доступная информация:**
- Процент явки
- Часы переработки
- Отклонения от графика
- Статистика опозданий

## 3. Сотрудник - Просмотр данных

### 3.1 Личный график

**Возможности:**
- ✅ Просмотр своего расписания
- ✅ Просмотр будущих смен
- ✅ Просмотр истории работы

## 4. Безопасность и ограничения

### Контроль доступа

```
Admin
├── Может видеть: всё
├── Может редактировать: всё
└── Может удалять: всё (с подтверждением)

Manager
├── Может видеть: свой объект и его сотрудников
├── Может редактировать: данные о своих сотрудниках
└── Может удалять: только свои табели

Employee
├── Может видеть: свой график и табели
└── Может редактировать: только заметки в своих табелях
```

### Row Level Security

- Все данные защищены RLS политиками
- Сотрудник не может видеть данные других сотрудников
- Менеджер не может видеть данные других объектов
- Администратор имеет полный доступ

## 6. Типичные рабочие сценарии

### Сценарий 1: Создание расписания на месяц

1. Админ входит в Dashboard
2. Выбирает "Расписания"
3. Создаёт новое расписание
4. Выбирает объект
5. Выбирает период (месяц)
6. Назначает сотрудников на смены
7. Сохраняет расписание

### Сценарий 2: Менеджер отмечает прихода сотрудника

1. Менеджер входит в систему
2. Переходит на "Табелирование"
3. Видит список сотрудников на смену
4. Нажимает "Check-In" для сотрудника
5. Система сохраняет время прихода
6. В конце смены нажимает "Check-Out"

### Сценарий 3: Анализ статистики

1. Менеджер переходит на "Команда"
2. Выбирает период
3. Видит статистику присутствия
4. Может экспортировать отчёт

## 7. Уведомления и предупреждения

- ⚠️ Предупреждение если сотрудник не явился на смену
- ⚠️ Предупреждение при дублировании смен
- ✅ Подтверждение при создании расписания
- ✅ Уведомление при подтверждении табеля

- Пагинация при большом количестве записей
