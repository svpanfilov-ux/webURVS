# Объединённое приложение Staff Schedule & Timesheet - Итоговый отчёт

## ✨ Что было создано

Полнофункциональное веб-приложение для управления штатным расписанием, графиками сотрудников и табелированием, объединившее два исходных проекта в одно мощное решение.

## 📦 Технологический стек

- **Frontend:** Next.js 16 (React 19, TypeScript)
- **Стили:** Tailwind CSS 3.4
- **База данных:** Supabase (PostgreSQL)
- **Аутентификация:** Supabase Auth
- **Хостинг:** Vercel / Любой Node.js хост
- **Иконки:** Lucide React
- **Диаграммы:** Recharts

## 🗄️ Схема базы данных

**7 основных таблиц:**
- `profiles` - Профили пользователей с ролями
- `facilities` - Объекты/филиалы
- `positions` - Должности
- `employees` - Сотрудники
- `shift_templates` - Шаблоны смен
- `schedules` - Расписания сотрудников
- `timesheets` - Табелирование работников

**Все таблицы защищены Row Level Security (RLS)** для безопасности

## 🔐 Безопасность

- ✅ Row Level Security (RLS) на всех таблицах
- ✅ Аутентификация через Supabase Auth
- ✅ JWT токены для API
- ✅ HTTP-only cookies для сессий
- ✅ Параметризованные SQL запросы (защита от SQL injection)
- ✅ Input validation и sanitization
- ✅ Role-based access control (RBAC)

## 📊 API Маршруты

```
POST   /api/auth/login          - Логин
POST   /api/auth/sign-up        - Регистрация
POST   /api/auth/logout         - Логаут

GET    /api/facilities          - Получить объекты
POST   /api/facilities          - Создать объект

GET    /api/positions           - Получить должности
POST   /api/positions           - Создать должность

GET    /api/employees           - Получить сотрудников
POST   /api/employees           - Добавить сотрудника

GET    /api/schedules           - Получить расписания
POST   /api/schedules           - Создать расписание

GET    /api/timesheets          - Получить табели
POST   /api/timesheets          - Создать табель
```

## 🚀 Как начать

### 1. Локально (5 минут)
```bash
npm install
cp .env.example .env.local
# Добавьте Supabase ключи в .env.local
npm run dev
```

### 2. На Vercel (10 минут)
```bash
git push origin main
# Vercel автоматически развернёт
# Добавьте переменные окружения в Vercel dashboard
```
